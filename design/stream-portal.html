Accessibility notes

Text contrast (re-measured 2026-10-21): Slate 900 on white 17.9:1 (AAA); Slate 600 on white 7.6:1 (AAA); status text/background pairs 6.4–7.2:1 (all pass AA; only the info pair reaches AAA). Primary blue #0EA5E9 on white is 2.77:1 — below AA for body text and below the 3:1 minimum for large text and non-text UI, so it must not carry text or be the only cue. For filled controls with white text use the solid token #0A79AD (4.83:1, AA).

Minimum sizes: 16px body (elderly-friendly, since stroke patients skew older), 16px inputs (prevents iOS zoom), 44px+ touch targets throughout.

Focus: 3px primary-blue ring at 50% opacity, 2px offset, visible on every interactive element via :focus-visible. Skip-to-content link on every screen. prefers-reduced-motion disables non-functional animation.

ARIA: alerts use role="alert"/aria-live, tabs use the tablist/tab/tabpanel pattern, active nav uses aria-current="page", icon-only buttons always carry aria-label.
